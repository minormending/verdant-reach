# Decisions

All of the first round of open questions was settled on 2026-10-04 by taking
the recommended option. The other docs reflect these answers.

| # | Question | Decision | Notes |
|---|---|---|---|
| Q1 | Region name | **Verdant Reach** | Working name; easy to rename later |
| Q2 | What the creatures are called | **Quickened** | Old English *quick* means alive |
| Q3 | Faces? | **No faces**: personality through animation | Matches the art pipeline. Needs the animation test below to confirm. |
| Q4 | Species names | **Real name plus stage word** | Oak Acorn → Oak Sapling → Great Oak. Convention in [05](05-key-plants.md#naming-convention). |
| Q5 | Type chart | **9 core types**: Wood, Fire, Water, Bug, Bloom, Ghost, Thorn, Frost, Dragon | Poison, Psychic, Dark, Flying and Rock are deferred until the battle system exists. Until then, the Council fields core types (see [03](03-characters.md#the-council-elite-four-and-the-keeper-champion)). |
| Q6 | Starter triangle | **Wood / Fire / Water**: oak, chili, giant water lily | Water > Fire > Wood > Water |
| Q7 | Fungi, algae, lichen | **Environment only**: never creatures | The network is fungal; the Glow field move uses an item, not a creature |
| Q8 | Seed Vault's role | **Post-game dungeon** | Act 2's set-piece stays the Root Relay |
| Q9 | Who reveals the twist | **Files at Bloom Lake; Bram confirms it at the Root Relay** | |
| Q10 | Post-game scope | **Seed Vault, Wanderers and Methuselah first** | The Far Shore (second region) is deferred until the main game exists |
| Q11 | Roster size | **About 100 species** (about 250–300 sprites) for v1 | |
| Q12 | Rival's stolen starter | **Strong against the player's** | |

## Still to validate

These are tests, not decisions:

- **An animation test** for one line (oak or water lily): does a faceless
  plant feel alive with 2–3 frames of idle motion? If not, revisit Q3.
- **A back-sprite test.** Plants are nearly symmetric, so mirrored, darkened
  back sprites may be enough, which would halve art scope.
- **Fact-check** every ✦ fact in [05](05-key-plants.md) before it ships in an
  herbarium entry.
