# Verdant Reach

A Game Boy Color–style monster collector in which every creature is a real
plant. You're a junior botanist. The night a once-a-century flower blooms,
certain plants across the valley wake up, and your job is to catalogue the
QUICKENED. Then you find out who woke them, and why.

This is a **vertical slice**: the Prologue and Act 1, ending at Conservatory 2,
about 60–90 minutes of play. The story bible lives in
`../creature-sprites/story/`.

## Play

```bash
npm install
npm run dev
```

Then open http://localhost:5173. For a production build, run `npm run build`
and serve `dist/` with any static server.

| Button | Keys |
|---|---|
| Move | Arrows / WASD (hold **B** to run) |
| A | Z, Space, J |
| B | X, Esc, Backspace, K |
| START (menu) | Enter |
| SELECT | Shift |

Time of day follows your real clock: morning 4–10, day 10–18, night 18–4.
Some plants only appear at night. Add `?time=morning|day|night` to the URL to
override it.

## What's in the slice

- **17 maps.** From the home town through Fallowfield, Hedgerow, Bramblegate and Sugarbush, with the Sugarbush Grove dungeon.
- **24 trainers.** Leaders HOLLIS (Wood) and NELL PITCHER (Bug), rival BRAM ×2, and ROOTSTOCK grunts with their admin SHEARS.
- **37 species, 71 moves and 9 types.** Every species is a real plant that grows through its real life stages, and every Field Herbarium entry contains a fact-checked true fact.
- **Systems:**
  - Crystal-style battles: physical/special split, statuses, weather, catching with critical captures, exp sharing.
  - Growth (evolution): by level, by time of day, and by friendship.
  - Party, bag, Field Herbarium, storage cabinet, shop and options.
  - Saving, whiteout, and a day/night tint.
- **An original chiptune soundtrack:** 21 tracks, jingles, sound effects and a cry per species, all synthesised live with WebAudio.
- **Art:** species sprites traced from public-domain and CC BY photos by the pipeline in `../creature-sprites`. Tiles, buildings, characters, portraits and UI are generated by `tools/art/`. Photo credits are in `public/assets/CREDITS.md`.

## Known limitations

- **Not yet listened to by a person.** The audio was checked only by measurement, so it still needs a listening pass for mix and feel.
- **Some sprites are weaker** (credited stand-ins listed in CREDITS.md): sundew, blackberry, bramble berry, lily seedpod, moonflower vine and seed, giant lily, ostrich fern, green chili.
- **Balance comes from simulation** (`src/battle/logic/balance.test.ts`), with every starter able to win every boss. Human play-testing still matters.
- **Missing features:**
  - you can't nickname a Quickened after catching it (only gifts can be nicknamed);
  - there's no move reordering;
  - there are no touch controls.
